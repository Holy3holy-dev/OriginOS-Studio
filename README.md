## Что тестируем в 1.4.0-beta2 (`global-beta`)

• [BETA 2] Исправлен сброс палитры «Системного стиля» Vivo после применения значков через com.bbk.theme: теперь выбранный системный цвет (или автоинициализация при выключенных тумблерах) сохраняется автоматически, значки красятся с первой секунды и мгновенно реагируют на смену цвета в Настройках телефона;
• [BETA 2] Эталонное «Жидкое стекло» от Системного стиля для 100% приложений: Google, системные и ~85% приложений с <monochrome> (Telegram, Discord, TikTok, ВК, банки и др.) перекрашиваются нативно на лету, а старые игры без <monochrome> (Roblox, Чижик, Темы, V-Appstore) рендерятся по той же альфа-линзе BlendMode.SRC_IN;
• [BETA 2] Полная поддержка любых иконок в Бета-движке: сторонние APK-иконпаки из каталога/Play Маркета, импортированные архивы (.itz / .mtz / .zip) и точечные кастомные иконки [✎] с поддержкой капсул 2×1 / 1×2 / 2×2;
• [BETA 2] Умное автоприменение по умолчанию: после выбора нового цвета в «Системном стиле» Vivo и выхода на рабочий стол Студия автоматически обновляет оставшиеся игры и кастомные иконпаки в новый системный цвет.
