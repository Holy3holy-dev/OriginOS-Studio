## Что тестируем в 1.4.0-beta6 (`global-beta`)

• [BETA 6] Единый 1:1 размер для ВСЕХ иконок в сторонних APK-иконпаках (Material 3 White / Dark и др.): убраны прозрачные поля вокруг подложки <iconback>, из-за которых непокрытые иконки и системные утилиты рендерились уменьшенными (159px вместо 193px);
• [BETA 6] Автоопределение двухцветных карточных иконпаков (Material 3 White / Dark) + контурный детектор Собеля для новых сложных приложений без монохромного слоя (клиенты VPN и игры больше никогда не становятся пустым белым квадратом!);
• [BETA 6] Полное раскрытие масштаба 140% (236px на холсте 240×240 + компенсация 62/59 для Google и док-бара) и автосинхронизация размера виджетов 1×1 с масштабом рабочего стола;
• [BETA 5] Полная защита и автовосстановление Always On Display («Всегда на экране» / com.vivo.nightpearl) в 1 касание.
