## Что нового в 1.1.0 (`global`)

- **Никаких сторонних программ (Shizuku больше не обязателен):** полноценный модуль беспроводного сопряжения (SPAKE2 + ADB over TLS 1.3) встроен прямо внутрь самой Студии с удобным вводом 6-значного кода прямо в шторке уведомлений;
- **Автономная работа на мобильном 4G без Wi-Fi:** после 30-секундной привязки Wi-Fi можно сразу выключить — встроенный демон Студии и локальный канал `5555` продолжают применять системные пакеты иконок `.itz` и шрифты `.ttf` / `.otf` прямо на мобильной сети 4G без Wi-Fi;
- **100% перекрашивание всех значков под выбранный иконпак**, бесшовные значки Google 1:1 без углового бейджа и общий облачный каталог тем, шрифтов, иконпаков и обоев.
