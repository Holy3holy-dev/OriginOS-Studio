## Что нового в 1.2.4 (`global`)

- **Исправлен экран «Нет ресурсов» в системных Темах Vivo (включая работу с активным VPN):** применение шрифтов, эмодзи, полных тем и пакетов значков теперь передаёт строго валидные числовые идентификаторы бесплатных карточек для всех трёх региональных кластеров Vivo (`ru-theme-api`, `eu-theme-api`, `asia-theme-api`);
- **Автоматическая ротация слотов предпросмотра:** при переключении между темами и шрифтами исключаются как скачанные записи `ResDbUtils`, так и кросс-кластерные идентификаторы;
- **Эмодзи с iPhone (Apple iOS 26.4 Emoji) без root в 1 касание:** 4 500+ объёмных 3D-смайлов Apple с автозащитой системных часов и цифр `0–9`.
