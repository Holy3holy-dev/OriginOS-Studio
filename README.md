## Что тестируем в 1.4.0-beta5 (`global-beta`)

• [BETA 5] Исправлено исчезновение Always On Display (Всегда на экране / com.vivo.nightpearl) после применения полной темы: исключён модуль 0x72 (AllClockApply), который записывал донорский ID темы вместо заводского циферблата AOD;
• [BETA 5] Добавлено автоматическое самовосстановление AOD при запуске приложения и кнопка «🔧 Восстановить работу AOD (Всегда на экране)» во вкладках «Темы», «Система» и на главном экране (если обнаружен сбой стиля AOD);
• [BETA 4] Крупные виджеты иконок 1×1 вровень с док-баром + ползунки масштаба (65%…140%) и вертикального выравнивания, приоритетный цвет иконпака для значков Google и системных приложений Vivo, регулировка размера папок;
• [BETA 3] Автоподтверждение диалога Тёмного режима в com.bbk.theme, защита тёмных паков днём от белых пятен и автоскругление паков ColorOS.
