# Студия OriginOS (OriginOS Studio)

**Версия:** `2.7.1 (build 98) • RU / EN`  
**Автор:** [H3H • Telegram: @holy3holy](https://t.me/holy3holy)  
**Платформа:** Vivo / iQOO (OriginOS 4 / 5 / 6 / 7 & Funtouch OS 14–15 • Android 14–17)

## О проекте

**Студия OriginOS** — самостоятельный центр кастомизации для смартфонов Vivo и iQOO, позволяющий применять **в 1 касание** (без root, ПК и Shizuku):
- **Значки в 6 стилях:** *Material You (Monet)*, *Nothing Dot Matrix (28×28 светодиодная матрица с индикатором Nothing Red)*, *Полноцветные 1:1*, *Стекло OriginOS*, *AMOLED Глянец*, *Цветные + подушка* (с поддержкой любых сторонних APK-иконпаков, регулятором размера значков 85%–130% и точечной заменой значков);
- **Собственные полные темы (`.itz`)** с сохранением родных индикаторов системного статус-бара OriginOS;
- **Системные кириллические шрифты (`.ttf` / `.otf` / `.ufont`)** без слёта и пробного периода (62 шрифта в каталоге, включая **Kabel**, **Google Pixel — Google Sans / Roboto Flex**, **Samsung One UI — SamsungOne / Sharp Sans**, **Apple iOS — SF Pro**, **Huawei HarmonyOS Sans**, **Xiaomi MiSans**, **OnePlus Sans**, **Nothing NDot 47**, **ASUS ROG Chakra**);
- **Домашние виджеты OriginOS & Material You** («Часы и День 4×2», «Календарь 2×2», «Классические стрелочные и цифровые часы 2×2») + встроенная витрина из **12 сторонних комплектов виджетов**.
