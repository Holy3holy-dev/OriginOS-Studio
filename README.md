## Что нового в 1.1.2 (`global`)

- **Изоляция игр на общих движках (UE4 / Unity / Godot):** исправлена коллизия активностей вроде `SplashActivity`, из-за которой `PUBG Mobile` и `Delta Force` получали одинаковый значок;
- **Целые акционные и двухцветные значки (Wildberries и др.):** новый построчно-волновой алгоритм чисто удаляет двухцветные плашки и шапки распродаж, сохраняя обе половины логотипа на 100%;
- **Nothing Dot Matrix для сервисов Google:** защищённые значки Google (`Chrome`, `Google Кошелёк`, `YouTube`, `Play`) автоматически получают тёмную матричную подложку Nothing OS на главном экране, а обновлённый мастер «Значки Google 1:1» позволяет заменить любой значок одним нажатием `＋` с опцией скрытия подписи;
- **Встроенный беспроводной движок (без Shizuku) и работа на мобильном 4G без Wi-Fi**, плюс полная совместимость с **OriginOS 7 Global (Android 17+)**.
